# Homebrew tap for console2svg

This repository is the official Homebrew tap for [console2svg](https://github.com/arika0093/console2svg).

```sh
brew tap arika0093/console2svg
brew install console2svg
```

You can also install it without explicitly tapping first:

```sh
brew install arika0093/console2svg/console2svg
```

The formula is synchronized automatically from the latest stable GitHub Release of `arika0093/console2svg`.
